Story Time

A pretty audio book player for the linux desktop Get it

Features

  • Built for Audio Books

    Story Time remembers your playback position for each audiobook you play

  • Just Plays Files

    No library management that imposes an order on your existing library or copies files around without being asked.

    Supports .m4b, m4a, and .mp3

  • a clean ui

    Built on Flutter for pretty animations and low resource usage.

    Feels right at home on a desktop and doesn't drag around a whole web browser.

And all the ther things you'd expect

  • sleep timer
  • playback speed control
  • chapter seeking
  • ability to unskip accidentally nudging the play position
